## What it is
A creator studio and an on-device player for short explainer lessons in English and Arabic (right to left). It has narration (Gemini TTS, with Whisper word alignment), an MCP server so AI clients can build lessons, and an MP4 export.

## Ngrok: how a bot reaches the local server
1. Start the server: `npm start -w @lessonstudio/server`. It serves MCP over HTTP on 127.0.0.1:4320. `apps/server/src/stdio.ts` is the stdio entry for local clients.
2. Start the tunnel: `ngrok http 4320 --url <your reserved domain>`. The domain goes in `LS_PUBLIC_URL` in `.env.local`. Don't print it.
3. A client adds `https://<domain>/mcp` as a custom connector. Sign-in is the user's Google account, and the server allows only listed emails.

The PC must be on and the server running. The bot's MCP access goes through this server, not the hosted one.

## The Darsi pipeline, per lesson
The id is the lesson id, for example `data-2-1-3`.

1. **Convert:** `node scripts/darsi/convert.ts <ID>`. It writes `content/darsi/lessons/<id>/` and checks it. Expect 0 errors and 0 warnings. **Always pass an id.** Without one, it regenerates all 12 original lessons.
2. **Layout check:** `npm run layout-check -- <id>` (both languages). Fix errors before narration. The template font errors listed below are the exception.
3. **Narrate, under the narration lock:** `npm run narrate -- --dir content/darsi/lessons/<id> --now --workers 6`. If it reports that not every sentence is voiced yet, run it again.
4. **Package and render:** `npm run package-lessons -- <id>` and `npm run mp4 -- <id> --lang en,ar-EG --sizes 240`. They write `out/packages/<id>/` and `out/videos/<id>/`. Contact sheets go to `out/sheets/`.
5. **Import into Darsi** (from `H:\htdocs\darsi`): `node scripts/import-media.mjs <unit>`. It copies the media into `content/media/<unit>/` and fills the video steps.
